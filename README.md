# KOL Management Website - Kelompok 6
Aplikasi web untuk pengelolaan data Key Opinion Leader (KOL), pekerjaan (brief) dari brand, serta pencocokan KOL dengan kebutuhan kampanye di Firstanova / PT. Siapamau Infinite Growth.

## 📋 Tentang Proyek
Proyek ini dikembangkan sebagai tugas mata kuliah Pengelolaan Proyek Sistem Informasi (AK-011415) untuk memberikan solusi digitalisasi pengelolaan KOL. Sistem menggantikan pencatatan dan pencarian KOL secara manual (spreadsheet) dengan platform web terpusat yang memungkinkan Admin mengelola data KOL dan pekerjaan, mencari serta memfilter kandidat, dan mencocokkan KOL dengan kriteria pekerjaan dari Brand.

## ✨ Fitur Utama
- 🔐 Login, registrasi (KOL & Brand), dan hak akses berbasis tiga peran: Admin, KOL, Brand
- 👤 Manajemen data KOL (tambah, lihat, ubah, hapus) dan profil KOL
- 💼 Manajemen data pekerjaan beserta kriteria (kategori, platform, followers, engagement)
- 🔎 Pencarian dan filter KOL berdasarkan nama, kategori konten, platform, followers, dan engagement
- 🤝 Pencocokan KOL dengan pekerjaan dan rekomendasi kandidat
- 📝 Daftar pekerjaan, pengajuan/minat pekerjaan, dan status pengajuan oleh KOL
- 👀 Brand dapat melihat profil dan detail kandidat KOL yang diajukan Admin (read-only)
- 🕘 Riwayat pencocokan KOL dengan pekerjaan (Could Have)
- 📱 Antarmuka responsif untuk laptop, tablet, dan ponsel

## 🛠️ Teknologi
- Backend: PHP, MySQL
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Server Uji: XAMPP (localhost)
- Server Produksi: Hosting web dengan dukungan PHP, MySQL, dan domain
- Design & Diagram: Figma, draw.io
- Version Control: GitHub (branch main dan dev, satu branch per fitur)
